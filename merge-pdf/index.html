    PDF GUIDE

    Combine PDF files while keeping the right order

    Merging PDFs can turn separate reports, forms, invoices, class notes or scanned pages into a single document. It is convenient when someone needs one attachment instead of several. Before merging, check that every source file belongs in the same document and that you are allowed to combine and share it.

    How to use PDF Merge

    1. Choose the PDF files you want to combine and confirm that each one opens correctly.
    2. Arrange the files in the desired sequence, if reordering is available. File selection order is not always the order people expect.
    3. Start merging and wait until the tool confirms the combined document is ready.
    4. Download the new PDF, then open it and check the beginning, end, page count and any pages that matter most.

    Tips and common mistakes

    Use descriptive filenames before you begin, especially when merging many similar documents. A merge generally preserves pages; it does not automatically correct rotated scans, remove sensitive pages, compress every image, or add bookmarks. Password-protected or damaged PDFs may fail unless they are unlocked or repaired first. If the final file is too large for email, check whether the source PDFs contain huge scans and use a suitable compression tool if available. Never assume a successful merge means every page is in the correct order; review the output before sending it.

    How merging works

    The browser-based tool reads the selected PDF documents, combines their page structures into a new PDF and prepares the output for download. The result depends on the source files and the capabilities of the PDF library. Forms, signatures, embedded media, bookmarks or unusual PDF features may not behave exactly the same after processing, so check the result for important documents.

    Privacy

    Your selected PDFs are processed in your browser and are not uploaded to a Kitlune application backend. The page may load its PDF-processing library from a third-party resource host. That resource request is separate from the contents of the PDFs you choose. For sensitive documents, use a trusted device and confirm that the final download is stored somewhere appropriate.

    Frequently asked questions

    Does merging reduce file size?

    Not necessarily. Combining files can produce a larger file; compression is a separate operation.

    Can I reorder pages?

    Use any available ordering controls before merging and verify the output afterwards.

    Will digital signatures remain valid?

    Editing or merging a signed PDF can invalidate signatures. Check signature requirements before processing.

    Why did a PDF fail?

    It may be damaged, encrypted, unusually structured, or too large for the available device memory.

    Are my PDFs uploaded?

    The tool is designed to process selected PDFs locally in your browser, not upload them to Kitlune.
