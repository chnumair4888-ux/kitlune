# Kitlune

**Free tools that run in your browser.**

Phase 1 contains the homepage, responsive design system, search and category filtering, light/dark theme toggle, custom SVG wordmark and favicon, and About, Contact, Privacy Policy, and Terms pages.

## Preview
This is a static website. Serve the folder from a local static web server or publish it to a static host. Root-relative links (such as `/assets/css/style.css`) assume the site is served from the domain root.

## Domain
Canonical and Open Graph URLs use `https://kitlune.site`.

## Ads
Ad placements are empty placeholders. No AdSense script is installed. Add ads only after approval, and update privacy and consent disclosures before enabling advertising cookies.

## Phase status
The seven tool cards are navigation previews for future phases; their processing pages are not included in Phase 1.
