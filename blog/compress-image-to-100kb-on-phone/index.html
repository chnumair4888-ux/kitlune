IMAGE GUIDE

How to compress an image to about 100 KB on your phone

Written by the Kitlune team•Last updated 23 October 2026

Some forms, portals and messaging systems set a small file-size limit for photos. If your image is several megabytes, the goal is not simply to make it as tiny as possible. The useful goal is to get close to the required size while keeping names, numbers, faces or other important details clear enough for the purpose.

This guide uses 100 KB as an example target. A compressor cannot always land on exactly 100 KB because the final size depends on the image dimensions, amount of detail, file format and compression method. If a website says “maximum 100 KB,” aim a little below the limit and check the final file before uploading.

Before you compress

Start with the best useful version of the image. If it is a document photo, crop away the table, wall or other background that is not part of the document. Straighten the page and make sure the text is in focus. Cropping can reduce file size without damaging the content because fewer pixels need to be stored.

Keep the original photo. Work on a copy so you can try again if the compressed version becomes too soft or blocky. This matters for IDs, receipts, certificates and other images where small text must remain readable.

Step by step on a phone

  1. Open the Kitlune Image Compressor in your phone browser.
  2. Select the image you want to reduce. The tool supports common web image formats shown on the tool page.
  3. Choose an output format and start with a moderate quality setting rather than immediately choosing the lowest quality.
  4. Compress the image and look at the resulting file size.
  5. If it is still above 100 KB, lower the quality in small steps and try again. If the image dimensions are unnecessarily large, resizing before compression can also help.
  6. When the result is below the required limit, download it and zoom in. Check the exact parts that matter: small writing, signatures, edges and faces.
Practical rule: the smallest file is not automatically the best file. Stop reducing quality once you meet the upload requirement and the important content still looks clear.

A real-world example

Imagine a phone photo of a one-page form is 2.8 MB. Most of the photo includes the desk around the page. First crop to the edges of the form. That alone removes unnecessary image area. Next compress the cropped copy at a moderate quality. Suppose the result is 180 KB. Reduce quality slightly and try again. If the next version is 92 KB and all form fields remain readable at normal zoom, that version meets a 100 KB maximum. If the text has become fuzzy, go back and try a better crop or smaller dimensions with less aggressive quality loss.

JPEG, PNG or WebP?

Photographs are commonly stored as JPEG because it can reduce photo data efficiently. PNG is useful for graphics and screenshots with sharp edges, but detailed photos saved as PNG can be large. WebP can often store web images efficiently, but the website receiving your upload may only accept JPG or PNG. The receiving site’s format rule comes first.

Common mistakes

Do not repeatedly compress an already compressed copy if you still have the original; repeated lossy compression can accumulate visible damage. Do not judge only by the thumbnail because tiny text may look fine until you zoom in. Avoid changing format just to get a smaller number if the destination does not accept that format. And do not upload the wrong copy after spending time preparing the correct one—check the filename and size in your phone’s file picker.

Frequently asked questions

Can I make every image exactly 100 KB?

Not reliably. Compression output varies with the image. For a maximum-size rule, a clear file below the limit is usually what matters.

Will compression change the image dimensions?

Quality compression and resizing are different operations. A tool may compress without changing width and height; check the tool settings and result.

Why does text become blurry?

Strong lossy compression removes visual information. Small text and fine lines can show artifacts sooner than large shapes.
