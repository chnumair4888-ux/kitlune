HOW KITLUNE WORKS

A small site with a clear purpose

1. Pick a task

Open a focused tool rather than installing a large app for a one-off job.

2. Use your own inputs

File tools work with the files you choose; calculators work only from the values you enter.

3. Check the explanation

Use the on-page notes and related guide to understand settings, assumptions and trade-offs.

4. Keep the output

Download the processed file or use the calculation as an educational planning estimate.
